# 归档

这里放**不再维护、但值得留着**的内容。归档不等于删除：整块搬进来、内部结构不动，为的是随时能搜到原文，也方便对比改写前后的差别。

## 归档规则

1. 整块搬入 `docs/归档/<名字>/`，保持原来的目录层次，这样旧的相对链接仍然可用。
2. 归档内容不进导航、不参与章节校验，也不要求符合现行规范。
3. 每个归档目录都要有一页说明：归档时间、为什么归档、替代它的是哪一页。
