# 零基础系统学计算机，先跟哪门公开课

**什么时候点进来**：刚进部门，没写过代码，分不清变量、函数、内存、算法各指什么，想找一门从零开始、讲得系统、有作业逼着动手的课。

## 一、什么场景用

- 完全没写过代码，或者只在课上学过一点 Python 语法但没独立做过东西。
- 想把「计算机到底怎么运行」这件事从头理一遍，而不只是学会某个工具的用法。
- 每天能挤出 1 小时左右，能承受一门课跟几周。
- 看英文字幕不吃力，或者愿意中英字幕对照着看。

如果你只是想先知道「计算机有哪些部分」，不用跟完整门课，看[计算机速成课](花十几个小时过一遍计算机常识.md)更快。

## 二、为什么是它

同类里能作为「第一门系统课」的还有几个：

- **计算机速成课（Crash Course）**：40 集、每集 10 分钟，动画讲原理，广度好、速度快，但**全程不写代码**。看完能建立地图，仍不会写程序，所以我们把它当前置预热，不作第一门课。
- **国内大学的计算机导论慕课**：结构完整，但很多是按考研与期末考试组织的，作业偏选择题，和「让程序真的跑起来」有距离。
- **B 站上的零散合集**：质量参差，缺作业与讲义，学到一半容易断。

CS50 的区别在于三件事同时具备：**从底层讲起**（二进制、算法复杂度、内存），**真的写代码**（先 C，再 Python、SQL、Web），**有强制动手的作业**（problem set 不做就学不会）。讲课有现场感，板书和代码是一步步写出来的，不是念 PPT。

## 三、怎么开始

- 国内视频站中文字幕合集：**待补**——由部门同学找到后补链接。不在这里随手填一个，避免版本不对或过期。
- 官方站（讲义、作业、字幕、更新版本）：<https://cs50.harvard.edu/x/>。**长期入口以官方站为准**，B 站合集只是转存，章节可能被下架。
- 官方提供在线开发环境，不用在自己电脑上装 C 编译器：<https://cs50.dev/>。

建议节奏：

1. 第 0、1 讲可以反复看，二进制与算法这两块是后面所有内容的地基。
2. 每讲的 problem set **自己先做一遍**，卡住再看官方 walkthrough（讲解视频）。
3. 先跟完 C 语言那几周，再进 Python。跳过 C 直接看 Python，会丢掉「内存与指针」这段最重要的理解。

## 四、代价与坑

- **课很长**。完整跟完是十周量级，中途放弃率不低。先承诺「跟完前三周」，比承诺「跟完整门」现实。
- **术语是英文**。中文字幕是翻译的，术语译法不统一；遇到关键概念，对照英文字幕或讲义原文记一次。
- **前两周的 C 语言会劝退**，尤其指针和内存。这一段建议放慢，作业一定自己写。
- **B 站合集不等于官方课程**。合集里的顺序与官方周次可能对不上，作业以官方站为准。

## 五、什么情况别用

- 已经能独立写一个小项目（哪怕只是脚本），想要系统课是浪费时间，直接按[学习路径](../学习/学习路径.md)选方向。
- 只是想查某个概念的定义，去[计算机基础](计算机基础.md)或对应参考页，不要为此跟整门课。
- 几天内要交作业或要上手干活，先看速成课，别从 CS50 开始。
