# 计算机基础

## 概述

计算机是按照程序自动处理数据的电子设备。

## 计算机组成原理

### 1. 冯·诺依曼体系结构

现代计算机大多基于冯·诺依曼体系结构，包含五个核心部件：

1. **运算器 (ALU)** - 执行算术和逻辑运算
2. **控制器 (CU)** - 指挥协调各部件工作
3. **存储器 (Memory)** - 存储程序和数据
4. **输入设备** - 接收外部信息
5. **输出设备** - 输出处理结果

**核心思想**：程序和数据统一存储，按顺序执行。

### 2. 核心硬件组成

#### 中央处理器 (CPU)

- **功能**：计算机的大脑，执行指令
- **主要部件**：运算器、控制器、寄存器
- **关键指标**：时钟频率、核心数

#### 主板与总线

- **主板**：连接所有硬件的平台
- **总线**：数据传输通道

### 3. 数据表示与存储

计算机用二进制（0 和 1）表示所有数据。

- **位 (bit)**：最小单位，取值 0 或 1
- **字节 (byte)**：8 位，是存储的基本单位

```text
1 KB = 1024 bytes
1 MB = 1024 KB
1 GB = 1024 MB
1 TB = 1024 GB
```

### 4. 指令执行过程

指令周期分五步：取指、译码、执行、访存、写回。流水线让多条指令同时处在不同阶段。

### 5. 存储系统

#### RAM (随机存取存储器)

- 特点：易失性，断电数据丢失
- 类型：DRAM（动态）、SRAM（静态）

#### ROM (只读存储器)

- 特点：非易失性，存储固件/BIOS
- 类型：PROM、EPROM、EEPROM、Flash

#### 硬盘与固态硬盘

- **机械硬盘 (HDD)**：磁性存储，机械结构，速度较慢
- **固态硬盘 (SSD)**：闪存存储，无机械部件，速度快

### 6. 性能指标

- **缓存大小**：影响数据处理速度
- **内存容量**：决定可同时运行的程序数量
- **带宽**：数据传输速率

计算机性能受限于最慢的部件（木桶原理），需要各部件协调工作。
