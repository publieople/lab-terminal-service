# Tailscale

**什么时候看这一套**：要把一台新机器接进实验室的私有网、要从宿舍连回实验室、要给一台没有公网 IP 的服务器一个稳定入口，或者用着用着连不上了。

## 一、这套讲什么

Tailscale 基于 WireGuard，用控制面下发密钥与网段信息，让设备之间直接建立加密隧道。设备加入同一个 tailnet 后，各自拿到稳定的内网地址与域名，跨 NAT、跨运营商都能互访。

Tailscale 解决的是「怎么让分散的设备互相访问」，不解决「服务器上跑什么」。所以这套只讲组网、路由、暴露与排障，服务本身的部署另看[参考](../README.md)里的对应页面。

适用：实验室的服务器、办公机与个人设备，以及需要远程接入的场景。

## 四、这套的边界

- **不重写官方文档**：命令参数以官方命令参考为准，这里只记实验室的实际用法与踩过的坑。
- **不做内网穿透的对照评测**：只讲当前在用的方案。
- **不代替账号与权限管理**：谁能进 tailnet、谁是管理员，按实验室分工在控制台维护。
- **不把 funnel 当免备案入口**：公网暴露要单独评估，见[排障与安全](05-排障与安全.md)。
