# VS Code

**什么时候看这一套**：刚装上编辑器不知道从哪开始、想连实验室服务器写代码、每次改代码都靠鼠标、或者用着用着某个功能坏了。

## 一、这套讲什么

实验室的日常工作里，读代码、改代码、写文档都经过同一个界面。编辑器不顺手，后面每一项工作都跟着慢。

这套按「装上并连上 → 键盘操作 → 设置与插件 → 调试与终端 → 出问题怎么查」组织，每页只讲一类事。

## 四、这套的边界

- **不重写官方文档**：快捷键全表、设置项含义以官方为准，这里只挑实验室常用的部分。
- **不教编程语言**：语法、框架由各自的课程负责。
- **不覆盖 JetBrains 系**：团队里有人用 IDLE 或 PyCharm，配置不在本套范围。
- **远程开发依赖组网**：连服务器前先能进 tailnet，见 [Tailscale 专题](../Tailscale/README.md)。
