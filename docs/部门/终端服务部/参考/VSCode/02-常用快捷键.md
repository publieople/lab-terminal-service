# VS Code 常用快捷键

## 一、这页讲什么

快捷键不需要背全表。真正省时间的是十来个高频组合：打开命令、切文件、跳行、选同名词、移动整行。

读完能做到：用键盘完成打开文件、跳转、多光标编辑、注释与格式化；按自己的习惯改键位。

## 二、开始之前

| 项 | 内容 |
| --- | --- |
| 版本与日期 | VS Code 1.10x；2026-10-21 核实 |
| 预计耗时 | 10 分钟 |
| 前置 | 已经装上并连上目标环境，见 [01-安装与远程开发](01-安装与远程开发.md) |
| 风险级别 | 低 |

本页按 Windows / Linux 布局书写：`Ctrl` 在 macOS 上对应 `Cmd`，`Alt` 对应 `Option`。

## 三、动手做

### 1. 先记三个万能键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + Shift + P` | 命令面板：任何功能都能搜到，不用记菜单 |
| `Ctrl + P` | 按文件名快速打开 |
| `Ctrl + \`` | 开关集成终端 |

看到这个就算成：这三个组合不查资料能直接按出来。

### 2. 打开与切换文件

| 按键 | 作用 |
| --- | --- |
| `Ctrl + P` | 按名字打开文件 |
| `Ctrl + PgUp` / `Ctrl + PgDn` | 在已打开的编辑器之间切换 |
| `Ctrl + Tab` | 列出最近打开的文件 |
| `Ctrl + N` / `Ctrl + W` | 新建 / 关闭当前文件 |
| `Ctrl + Shift + N` | 新开窗口 |

看到这个就算成：在五个以上文件之间切换全程不碰鼠标。

### 3. 在文件内跳转

| 按键 | 作用 |
| --- | --- |
| `Ctrl + G` | 跳到指定行 |
| `Ctrl + Shift + O` | 跳到当前文件的符号（函数、类） |
| `Ctrl + T` | 跨文件搜符号 |
| `Ctrl + Shift + \` | 跳到匹配的括号 |
| `Ctrl + U` | 光标退回上一个位置 |

看到这个就算成：能在一秒内跳到某个函数定义、跳回刚才的位置。

### 4. 改动代码

| 按键 | 作用 |
| --- | --- |
| `Ctrl + /` | 注释 / 取消注释 |
| `Alt + ↑` / `Alt + ↓` | 整行上移 / 下移 |
| `Alt + Shift + ↑` / `↓` | 复制整行 |
| `Ctrl + Shift + K` | 删除整行 |
| `Ctrl + Enter` | 在当前行下方插入新行 |
| `Ctrl + Backspace` / `Ctrl + Delete` | 按词删除 |
| `Alt + Shift + F` | 格式化当前文件 |
| `F2` | 重命名符号（会同步改引用） |

看到这个就算成：移动、复制、删除整行都不需要先选中。

### 5. 多光标与批量改

| 按键 | 作用 |
| --- | --- |
| `Alt + 点击` | 在点击处加一个光标 |
| `Ctrl + D` | 选中下一个相同的词 |
| `Ctrl + Shift + L` | 选中所有相同的词 |
| `Ctrl + Alt + ↑` / `↓` | 上下加一列光标 |
| `Alt + Shift + I` | 每行末尾加光标 |

看到这个就算成：一次改掉同名变量或同格式的十行配置。

### 6. 搜索

| 按键 | 作用 |
| --- | --- |
| `Ctrl + F` | 文件内搜索 |
| `Ctrl + H` | 文件内替换 |
| `Ctrl + Shift + F` | 全工作区搜索 |
| `Ctrl + Shift + H` | 全工作区替换 |
| `F3` / `Shift + F3` | 跳到下一个 / 上一个匹配 |

看到这个就算成：能在整个工作区里定位一处调用，并确认有几处。

### 7. 改键位（可选）

`Ctrl + K` 然后 `Ctrl + S` 打开快捷键设置，搜索命令后直接按新组合。改动写进 `keybindings.json`，可以跟随设置同步。

```json
[
  { "key": "ctrl+alt+t", "command": "workbench.action.terminal.new" }
]
```

看到这个就算成：自定义键位生效，且能在 `keybindings.json` 里看到那条记录。

## 四、做完怎么确认

1. 打开文件、切文件、跳行、跳符号都能用键盘完成。
2. 整行移动、复制、删除不需要先选中。
3. 能用 `Ctrl + D` 一次改掉多个同名标识。
4. 至少有一条自己的自定义键位。

## 五、卡住了怎么排查

| 症状 | 多半是 | 先验证 | 处理 |
| --- | --- | --- | --- |
| 某个组合没反应 | 被输入法或系统快捷键占用 | 关掉输入法再试一次 | 换组合，或系统里释放该组合 |
| `Ctrl + Shift + P` 无反应 | 焦点不在编辑器 | 点一下编辑区再按 | 先聚焦编辑区 |
| 自定义键位不生效 | JSON 语法错误，或命令名写错 | 命令面板执行 `Preferences: Open Keyboard Shortcuts (JSON)` 看提示 | 修 JSON；命令名从快捷键面板复制 |
| 与旧编辑器习惯冲突 | 键位不同 | — | 在快捷键设置里改成自己熟悉的组合 |
| 远程窗口里快捷键不同 | 远程窗口有自己的键位设置 | 左下角确认连接状态 | 在远程窗口里重设 |

## 六、为什么这样能成

**命令面板是快捷键的目录。** 每个快捷键背后都是一条命令，记不住组合时从命令面板搜命令名，旁边的提示会显示当前键位，按几次就记住。

**多光标按结构选，不按位置选。** `Ctrl + D` 按相同文本选，改动不会漏掉某一行；手动点出来的光标容易漏。

**键位写在 JSON 里。** 设置同步能带走 `keybindings.json`，换机器时不用重配。

## 七、边界与替代

- **不替代输入法快捷键**：输入法自有组合时，编辑器不一定抢得到。
- **不追全表**：官方 PDF 有完整清单，本页只到高频部分。
- **不在远程窗口里另设一套**：远程窗口共用同一份键位，另设会出现「本地能用、远程不能用」。
- **Vim 模式另算**：装了 Vim 扩展后部分组合被接管，键位以扩展为准。
