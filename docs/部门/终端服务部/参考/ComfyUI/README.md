# ComfyUI

**什么时候看这一套**：要在实验室的机器上装 ComfyUI、出第一张图，或者用着用着卡在某个具体问题上。

## 一、这套讲什么

ComfyUI 把「加载模型 → 写提示词 → 采样 → 出图」画成节点图，点一次执行整条流程。它不是装完就结束的工具：装法、模型目录、节点、显存、升级各是一摊事，所以拆成几页，每页只讲一件。

适用：实验室里带 NVIDIA 显卡的机器。Windows 走便携版，Linux 服务器走源码安装，两条路都在[部署](01-部署.md)里。

## 四、这套的边界

- **不重写官方文档**：装法、参数、界面以官方为准，这里只记实验室的实际路径、内部约定和踩过的坑。
- **不教调参美学**：提示词怎么写、采样器怎么选属于出图经验，写在[经验](../../经验/README.md)。
- **不替代内部台账**：模型盘位置、GPU 服务器入口、端口登记在内部台账，这里只说明去哪里查。
- **一台机器别装多套**：多人共用时走实验室统一入口，不要每人各起一份，否则显存互相抢。
