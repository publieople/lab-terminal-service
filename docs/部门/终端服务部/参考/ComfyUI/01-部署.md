# ComfyUI 部署

## 一、这页讲什么

把 ComfyUI 装到一台机器上，启动起来，确认显卡被认到、面板能打开。

装完会得到：浏览器能访问的面板（默认 `127.0.0.1:8188`）、一个不会被其他 Python 项目干扰的独立环境、以及别人访问这台机器的两种办法。出第一张图见[02-第一次出图与界面](02-第一次出图与界面.md)。

## 二、开始之前

| 项 | 内容 |
| --- | --- |
| 版本与日期 | ComfyUI 2026-10 最新版；Python 3.13；PyTorch CUDA 13.0；2026-10-20 核实 |
| 预计耗时 | 20 到 40 分钟，不含下载模型 |
| 前置 | NVIDIA 显卡与较新驱动；Windows 需 7-Zip，Linux 服务器需 Git 和 conda |
| 风险级别 | 低：全新安装，不改动系统 Python |

Windows 电脑走 A，Linux GPU 服务器走 B。AMD、Intel、macOS 见第七节。官方不提供 Docker 镜像，社区镜像不受支持。

## 三、动手做

### A. Windows 便携版

#### 1. 下载并解压

在 <https://docs.comfy.org/installation/comfyui_portable_windows> 按显卡选包：RTX 20 系以上用 `ComfyUI_windows_portable_nvidia.7z`，GTX 10 系及更老用 `ComfyUI_windows_portable_nvidia_cu126.7z`。用 7-Zip 解压到纯英文路径。

看到这个就算成：目录里有 `ComfyUI\`、`python_embeded\`、`run_nvidia_gpu.bat`。

#### 2. 启动

双击 `run_nvidia_gpu.bat`，窗口出现：

```text
To see the GUI go to: http://127.0.0.1:8188
```

浏览器会自动打开，没开就手动访问。**这个窗口全程不能关**，关掉服务就停。

#### 3. 让同组网设备访问（可选）

记事本打开 `run_nvidia_gpu.bat`，启动参数加 `--listen`：

```bat
.\python_embeded\python.exe -s ComfyUI\main.py --listen --windows-standalone-build
```

看到这个就算成：窗口地址变成 `http://0.0.0.0:8188`，别人访问 `http://<局域网IP>:8188`。

警告：面板没有登录，`--listen` 等于开放给整个网段。只在可信网络里开，跨网段走 Tailscale 或反向代理。

#### 4. 升级

进 `update\` 双击 `update_comfyui.bat`。环境坏了才用 `update_comfyui_and_python_dependencies.bat`。

### B. Linux GPU 服务器

#### 1. 建环境取代码

```bash
$ conda create -n comfyenv python=3.13
$ conda activate comfyenv
$ git clone https://github.com/Comfy-Org/ComfyUI.git
$ cd ComfyUI
$ python -V
Python 3.13.x
```

看到这个就算成：最后一行是 `Python 3.13.x`，目录里有 `main.py`。

#### 2. 装 GPU 版 PyTorch

```bash
$ pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
$ python -c "import torch; print(torch.cuda.is_available(), torch.version.cuda)"
True 13.0
```

看到这个就算成：输出 `True 13.0`。输出 `False` 说明装成 CPU 版或驱动太旧，见第五节。

#### 3. 装依赖并启动

```bash
$ pip install -r requirements.txt
$ python main.py
To see the GUI go to: http://127.0.0.1:8188
```

看到这个就算成：`pip` 没有 `ERROR` 行（`WARNING` 可忽略），最后一行是上面那个地址。

#### 4. 从自己电脑访问（可选）

```bash
$ ssh -L 8188:127.0.0.1:8188 <用户名>@<服务器地址>
# 输入密码后保持窗口不要关，关掉隧道就断
```

看到这个就算成：本地浏览器打开 `http://127.0.0.1:8188` 能出画面板，关掉 SSH 窗口后立刻打不开（说明没对公网开放）。

## 四、做完怎么确认

1. 面板能打开：`http://127.0.0.1:8188` 是节点画布，不是报错页。
2. GPU 被认到：`python -c "import torch; print(torch.cuda.is_available())"` 输出 `True`（便携版用 `.\python_embeded\python.exe` 跑）。
3. 环境是独立的：`python -V` 和系统 `python -V` 不是同一个路径。

## 五、卡住了怎么排查

| 症状 | 多半是 | 先验证 | 处理 |
| --- | --- | --- | --- |
| 页面打不开，窗口也没报错 | 地址用错，或服务已挂 | 看窗口 `To see the GUI go to:` 那行 | 用窗口打印的地址；窗口没了就重启 |
| `cuda.is_available()` 是 `False` | 装成 CPU 版，或驱动旧 | `$ nvidia-smi`、`$ pip show torch` | 按 B-2 重装 CUDA 版；升级驱动 |
| `pip install` 卡在下载 | 网络到 PyPI 慢 | 换镜像源重试 | 用国内镜像装依赖，PyTorch 仍用官方 index |
| 装完节点启动失败 | 依赖没装全，或节点本身有 bug | `$ python main.py --disable-all-custom-nodes` 能否起来 | 能起来就是节点问题：先用同一环境的 `pip` 补依赖，再逐个停用排查 |
| 同事打不开 | 没加 `--listen`，或被防火墙挡 | 在同事机器 `curl` 那个地址 | 加 `--listen`（可信网络）；跨网用 Tailscale |

## 六、为什么这样能成

**为什么必须独立环境。** ComfyUI 对 PyTorch 版本敏感，装进系统 Python 容易和别的项目打架。便携版把 Python 和 PyTorch 一起打包，所以解压就能跑。

**为什么驱动、CUDA、PyTorch 要配套。** 驱动决定能用哪个 CUDA，PyTorch 要装成对应构建（现在 `cu130`）。错位时最常见的结果是 `cuda.is_available()` 为 `False`：服务能开，但全在 CPU 上跑。

## 七、边界与替代

- **别用 Docker 镜像**：官方不提供，社区镜像出问题没人兜底。
- **显存很小的卡**：能跑但很慢，租云 GPU 或在线服务更划算。
- **多人共用一台服务器**：不要每人各起一份，走实验室统一入口（内部台账登记）。
- **不是 NVIDIA 显卡**：AMD 走 ROCm、Intel 走 XPU、Apple Silicon 走 Metal，按官方手动安装页选对应的 PyTorch。
