# ComfyUI 第一次出图与界面

## 一、这页讲什么

假设已经按[01-部署](01-部署.md)装好并启动，这一页解决两件事：认清界面上哪块是干什么的，然后完整走一遍文生图，出一张图。

读完你会有：一张自己出的图、一个能保存复用的工作流文件、以及知道每类操作该去界面哪个区域找。

## 二、开始之前

| 项 | 内容 |
| --- | --- |
| 版本与日期 | ComfyUI 2026-10 最新版；2026-10-20 核实 |
| 预计耗时 | 10 到 30 分钟，取决于下载模型的速度 |
| 前置 | [01-部署](01-部署.md)已完成，面板能打开 |
| 风险级别 | 低：只在本地出图，不改系统 |

第一次出图必须有一个 checkpoint 模型。模型文件通常几百 MB 到数 GB，先用实验室网络下好再放进模型目录，比在界面里等更稳。

## 三、动手做

### 1. 认清界面的六个区

官方把工作区分成六块，按编号找：

| 编号 | 区域 | 里面有什么 |
| --- | --- | --- |
| 1 | 左侧栏 | 素材（Assets）、节点库、模型库、工作流、应用 |
| 2 | 画布 | 放节点、连线的地方 |
| 3 | 右侧面板 | 选中节点的参数、节点信息、设置、报错 |
| 4 | 顶栏 | 打开工作流、运行/队列控制、登录、属性面板开关 |
| 5 | 左下角 | 帮助中心、日志与快捷键面板、设置 |
| 6 | 右下角 | 画布控制：平移、缩略图、连线可见性、缩放、适合窗口 |

看到这个就算成：能指着屏幕说出「节点参数在右侧、运行按钮在顶栏」。

界面默认英文。要中文：**设置 → Comfy → Locale** 里选语言（官方支持中、英、俄、法、日、韩）。

### 2. 载入一张模板工作流

空画布不适合手搓。用官方模板或带工作流信息的图片起步：

- 左侧栏 **工作流（Workflows）** 里有官方模板，选「文生图」这一类；
- 或者把别人分享的、带工作流元数据的图直接拖进画布，工作流会一起还原。

看到这个就算成：画布上出现一组连好的节点（加载模型、两个提示词框、采样器、解码、保存图像），不是空白。

不同版本这个入口的位置会变，以 <https://docs.comfy.org/get_started/first_generation> 为准。

### 3. 把模型放到位

模板里那个「加载模型」节点是缺模型状态时，界面会提示缺失并给出下载入口（官方支持自动安装）。手动装也可以：

- checkpoint 放进 `ComfyUI/models/checkpoints/`；
- 便携版就在解压目录下的 `ComfyUI\models\checkpoints\`。

看到这个就算成：点开「加载模型」节点的下拉框，能看到刚放进去的文件名。

放错目录的表现不是报错，而是**列表里看不见**——这是最常见的坑。

### 4. 写提示词并执行

模板里有两个提示词框：正面写你想要什么，负面写你不想要什么。写英文效果通常更稳，写完点顶栏的运行按钮。

看到这个就算成：队列开始跑、有进度显示，跑完画布上出现结果图，左侧「素材」里也能找到它。

### 5. 存下这个工作流

顶栏或左侧「工作流」里保存，会得到一个工作流文件。以后要重复出图，直接载入它，不用重新连节点。

看到这个就算成：重启界面后能在「工作流」列表里找到自己保存的那一份。

## 四、做完怎么确认

1. 出了一张图，能在左侧「素材」里看到并下载。
2. 工作流能保存、能重新载入。
3. 换一个 checkpoint 或改一句提示词，结果会变（说明参数确实生效）。

## 五、卡住了怎么排查

| 症状 | 多半是 | 先验证 | 处理 |
| --- | --- | --- | --- |
| 点运行没反应 | 队列里没有任务，或面板断连 | 看顶栏队列数字、看启动窗口有没有报错 | 刷新页面；窗口报错就重启服务 |
| 提示缺模型 | 模型没放或放错目录 | 打开模型下拉框 | 按第三节第 3 步放进 `models/checkpoints/` |
| 跑一半失败 | 显存不够 | 看窗口里的 OOM 报错、`$ nvidia-smi` | 降分辨率或换空卡；显存策略见后续页面 |
| 出图全黑或乱码 | 负面提示词过强，或模型与工作流不匹配 | 换回官方模板默认参数 | 先跑模板不改参数，确认能出图再调 |
| 中文提示词效果差 | 多数模型以英文语料为主 | 同一句改英文再跑 | 提示词用英文，界面语言才用中文 |
| 界面一直转圈 | 浏览器版本太旧 | 看浏览器版本 | 换新版 Chrome 或 Edge |

## 六、为什么这样能成

**节点图就是数据流。** 每个节点是一步运算，连线决定上一步的输出交给谁。看懂了连线，就知道改哪个节点会影响什么。

**工作流是一个文件。** 保存下来的工作流记录的是节点和连线本身，不含模型文件，所以换机器时要连模型一起搬。

**模型按用途分目录。** checkpoint 是整包模型，LoRA 是叠加的小补丁，VAE 负责解码——放错目录不会报错，只是列表里看不见。

## 七、边界与替代

- **这不是绘图软件**：它不提供笔刷和图层，出图靠模型和参数，想手改去别的工具。
- **只想快速试一次**：官方有在线服务，装本地不划算时先用在线版验证效果。
- **别在模板上乱改**：先跑通官方模板，再一个个换节点，否则出不来图时分不清是哪个改动的问题。
- **复杂工作流先抄再改**：社区工作流值得参考，但里面常绑定了特定模型和自定义节点，缺一个就跑不动。
