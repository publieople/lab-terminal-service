# 终端环境与配置

## 一、技术是什么

"终端"这个词在日常对话里指三样东西，配置走弯路通常是因为把它们混在一起：

| 层 | 是什么 | 常见选择 |
| --- | --- | --- |
| 终端宿主 | 显示字符、处理键盘鼠标、管理标签与分屏的窗口程序 | Windows 终端（Windows Terminal） |
| Shell | 解释你敲的命令、执行程序、渲染提示符的程序 | PowerShell 7、fish、bash、zsh |
| 提示符与外观 | 决定提示符显示什么信息、用什么字体与配色 | Oh My Posh、Starship、等宽字体 |

再加一层可选的**会话管理**（tmux、zellij），作用是在断线后让会话继续活着。

本页讲的是把这三层配成一套顺手的组合，不涉及具体的服务器运维命令（那部分见[Linux 服务器运维](Linux服务器运维.md)与[基础知识：终端与命令](../基础知识/终端与命令.md)）。

---

## 二、为什么使用

命令行是服务器上唯一稳定存在的界面：图形界面可能没装、可能被防火墙挡住、可能因为显卡驱动出问题起不来。远程连上去以后，你看到的就是一个提示符。

一个好用的终端环境解决四件事：

- **看得见状态**：提示符上直接显示当前目录、Git 分支、上一条命令的退出码与耗时，少敲几次确认命令；
- **少出错**：等宽字体让路径与参数对齐，Nerd Font 图标让分支、状态一眼能认；
- **少切窗口**：标签页与分屏把"本地编辑 + 服务器查看"放进一个窗口；
- **能复制粘贴**：报错原文、命令、日志可以直接复制，不需要手抄。

值得说清楚的是：**顺手的配置不等于花哨的配置**。主题、图标、动画都属于锦上添花；提示符里有没有退出码，才是真正影响排查速度的东西。

## 三、工作原理

在 Windows 上，字符是这么走到你眼前的：

```text
键盘输入
  → 终端宿主（Windows 终端）负责显示与快捷键
    → 分两条路：
       ① 本地：pwsh.exe（PowerShell 7）直接执行
       ② WSL：wsl.exe → Linux 发行版 → bash / fish 执行
    → 输出回到宿主渲染
```

几个由此推出的结论：

- **提示符是 Shell 的功能**，不是终端宿主的。换主题要去 Shell 侧配置，换字体去宿主侧配置。
- **WSL 里的 Linux 与 Windows 是两套文件系统**：`/mnt/c` 是跨系统访问 Windows 磁盘的挂载点，走的是 9p 协议，比在 Linux 侧读写慢很多。项目文件放在 Linux 侧的家目录里，速度差别很明显。
- **图标依赖字体**：提示符里的 Git 分支符号、文件夹图标来自 Nerd Font 的私有区码位。字体没装对，就会显示成方块。
- **换行符是两套规矩**：Windows 用 CRLF，Linux 用 LF。在 Windows 上编辑过的脚本拿到 Linux 跑，常见报错是 `bad interpreter: /bin/bash^M`。

## 四、使用环境

一台 Windows 机器配下来需要这些：

| 组件 | 建议 | 说明 |
| --- | --- | --- |
| 终端宿主 | Windows 终端 | 系统自带，从应用商店保持更新 |
| Shell（Windows 侧） | PowerShell 7 | 比系统自带的 5.1 新，跨平台，语法一致 |
| Shell（Linux 侧） | fish 或 bash | fish 的补全与提示开箱好用，但语法与 POSIX 不兼容 |
| Linux 环境 | WSL2（Ubuntu 或 Arch） | 装 Linux 命令行工具最省事的方式 |
| 提示符 | Oh My Posh（pwsh）/ Starship（fish） | 两者都能显示目录、Git 分支、退出码 |
| 字体 | Maple Mono NF CN、JetBrainsMono Nerd Font 等 | 要**等宽 + 带 Nerd Font 图标**；中文场景选带 CN 的版本 |
| 会话管理（可选） | tmux、zellij | 断线不丢会话，服务器上尤其有用 |

安装命令（`winget` 已在《[Windows 常用软件](../学习课程/Windows常用软件.md)》里讲过）：

```powershell
winget install --id Microsoft.PowerShell --exact
winget install --id JanDeDobbeleer.OhMyPosh --exact
wsl --install -d Ubuntu
```

字体需要单独装，装完在终端宿主的配置里指定字体名。

## 五、基本使用

### 5.1 先定默认 Shell

Windows 终端里 `Ctrl + ,` 打开设置，把默认配置文件设成平时最常用的那个（写代码多半是 WSL，跑 Windows 工具则是 PowerShell）。每次开窗少选一次，一天能省下几十次点击。

### 5.2 宿主的三个关键配置

Windows 终端的 `settings.json` 里，值得先改的只有下面几项：

```json
{
  "profiles": {
    "defaults": {
      "font": { "face": "Maple Mono NF CN", "size": 11 },
      "colorScheme": "One Half Dark",
      "startingDirectory": "."
    }
  },
  "actions": [
    { "command": { "action": "splitPane", "split": "auto" }, "keys": "alt+shift+d" },
    { "command": "toggleFocusMode", "keys": "shift+f11" }
  ]
}
```

`startingDirectory` 设成 `"."` 表示"新标签页从当前目录开始"，开新标签不用重新 `cd`。

### 5.3 提示符

PowerShell 侧（写进 `$PROFILE`）：

```powershell
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\jandedobbeleer.omp.json" | Invoke-Expression
```

fish 侧（写进 `~/.config/fish/config.fish`）：

```fish
starship init fish | source
```

验证提示符是否真的在工作：随便敲一条会失败的命令，看提示符上有没有出现非零退出码的标记。

### 5.4 每天都会用到的操作

| 想做什么 | 怎么做 |
| --- | --- |
| 新标签 / 分屏 | `Ctrl + Shift + T` / `Alt + Shift + D` |
| 复制粘贴 | 选中即复制；`Ctrl + Shift + V` 粘贴 |
| 命令历史搜索 | `Ctrl + R` |
| 跳到行首 / 行尾 | `Ctrl + A` / `Ctrl + E` |
| 中断当前命令 | `Ctrl + C` |
| 结束输入（退出 Shell） | `Ctrl + D` |
| 清屏 | `Ctrl + L` |

### 5.5 会话管理

连着服务器做事时，先起一个 tmux 会话：

```bash
tmux new -s work      # 新建名为 work 的会话
tmux attach -t work   # 断线后重新接上
```

这样网络断了、笔记本合盖了，服务器上的命令还在跑。

## 六、实际应用

在部门里，这套环境的用法集中在四件事上：

1. **连服务器**：先按[技术模块：Tailscale 组网](Tailscale组网.md)接入组网，再 `ssh <用户名>@<内网IP>`；常用机器写进 `~/.ssh/config` 起别名，之后一条 `ssh <别名>` 就进去。
2. **看日志与状态**：`tail -f`、`journalctl -u <服务名> -n 200`、`ss -lntp`。这些命令的用法见[Linux 服务器运维](Linux服务器运维.md)。
3. **传文件**：小文件用 `scp`，批量同步用 `rsync -av --progress`，比在图形界面里拖拽可靠。
4. **录制演示**：终端字体清楚、字号够大，录屏时观众才看得清命令。录屏工具见《[Windows 常用软件](../学习课程/Windows常用软件.md)》。

新成员第一天的收尾清单：

- 终端里 `echo $SHELL`（Linux 侧）能说出自己在用哪个 Shell；
- 能开一个分屏，一边编辑一边看服务器输出；
- 退出终端再打开，提示符里的目录与 Git 分支信息仍然正常显示。

## 七、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 中文显示成方块 | 字体没有中文字形 | 换带 CN 的等宽字体，例如 Maple Mono NF CN |
| 图标显示成方块 | 装的是普通等宽字体，不是 Nerd Font 版本 | 换 Nerd Font 版本 |
| 脚本报 `bad interpreter: /bin/bash^M` | 文件是 CRLF 换行 | 用 `dos2unix`，或在仓库里用 `.gitattributes` 固定 LF |
| 粘贴的命令多出奇怪字符 | 终端把粘贴内容当键盘输入 | 使用支持括号粘贴的终端，或改用 `Ctrl + Shift + V` |
| WSL 里编译 / 扫描特别慢 | 项目放在 `/mnt/c` 下，走 9p 跨系统访问 | 把项目移到 Linux 家目录 |
| fish 里跑不了网上抄来的脚本 | fish 语法与 POSIX 不同 | 用 `bash -c '<脚本>'` 执行，或改用 bash |
| 打开终端要等一两秒 | 提示符配置在启动时加载了太重的内容 | 换更轻的主题，或开启 transient prompt |
| `ssh` 卡住不返回 | 网络层或密钥认证问题 | 先 `ping` 网关与目标地址，再加 `ssh -v` 看卡在哪一步 |

## 八、延伸方向

- **命令行增强工具**：`fzf`（模糊查找）、`ripgrep`（快速搜索文件内容）、`bat`（带高亮的 `cat`）、`zoxide`（按使用频率跳目录）。这几个装完之后，日常敲命令的体感变化最大。
- **密钥登录**：生成密钥对、把公钥放到服务器，之后不再输密码，也便于自动化脚本。
- **团队统一配置**：把 Windows 终端的配置拆成 fragment 分发，新人装上即用，减少"每个人的终端都不一样、说不清怎么复现"的情况。
- **录制与分享**：把常用操作录成短片段放进培训材料，比文字步骤更容易复现。
