# 终端环境

**什么时候看这一章**：准备按部门文档部署服务之前。**我们要求每个人都有一套自己用顺手的终端**——照抄别人的配置只能应付一次，出了问题还是不会修。

## 一、这一章教什么

把「终端」拆成四层分别讲清楚，再串起来：

1. **终端宿主**：Windows Terminal、Windows 自带的控制台、xterm 类终端——窗口本身
2. **Shell**：PowerShell、bash、fish——真正解释命令的那一层
3. **提示符与外观**：提示符、字体、图标、配色——决定你愿不愿意天天用它
4. **会话管理**：多标签、分屏、会话保持——ssh 断开后命令还在不在

## 二、学完能做什么

- 能说清「我装的是终端还是 shell」，出问题时知道去改哪一层的配置
- 能在 Windows 和 Linux 上各配一套结构相同、细节适配的终端
- 换一台机器时，能把自己的配置带过去，而不是从头再调一遍
