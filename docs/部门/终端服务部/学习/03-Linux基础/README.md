# Linux 基础

**什么时候看这一章**：要连实验室的 Linux 服务器、或者按文档部署一个服务，但只会照抄命令，看不懂报错。

## 一、这一章教什么

按「登上机器之后真正会遇到的事」排序，而不是按命令手册的目录排：

1. 登录与权限：ssh、密钥、`sudo`、文件属主
2. 文件系统：目录习惯（`/etc`、`/var`、`/opt`）、挂载点、磁盘满了怎么看
3. 进程与服务：`systemd`、日志、开机自启、进程被谁杀掉
4. 包管理：发行版差异、从哪装、装坏了怎么退

## 二、学完能做什么

- 能只用命令行连上一台 Linux 机器，判断当前用户有什么权限
- 服务起不来时，能按顺序看单元状态、日志、端口三层，而不是先重装
- 能判断磁盘、内存、进程三类异常分别该看哪个命令
