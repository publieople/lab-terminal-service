# 文件与路径

**什么时候看这一讲**：教程里出现 `C:\Users\你\AppData\Local\Temp` 这样的路径，你不知道它对应磁盘上的哪个位置；或者明明文件就在眼前，程序却说"找不到文件"。

## 一、学习目标

学完这一讲，你能做这三件事：

- 拿到任何一条路径，能指出它由哪几段拼成、每段对应磁盘上的什么位置
- 自己拼出用户目录、桌面、下载、临时目录的完整路径，不用一层层点进去找
- 遇到"文件找不到"时，先判断是路径写错了、被系统隐藏了，还是权限不够

## 二、前置

不适用——这是全库第一讲，只要能打开资源管理器。

## 三、正文

### 3.1 路径是"从盘符开始的一段地址"

Windows 的路径用反斜杠分隔，从盘符一路写到文件名：

```text
C:\Users\publieople\Documents\报告\2026-10 月报.docx
│   │                │         │            │
盘符 用户目录          一级目录    二级目录      文件名
```

读路径的顺序和找东西的顺序一样：先看哪个盘，再一层层往下走。**中间任何一层名字对不上，最终都会报"找不到"。**路径写错的时候，通常错在某一层的名字或拼写上，而不是文件名。

### 3.2 三个最容易被忽略的目录

| 路径 | 放什么 | 什么时候会用到 |
| --- | --- | --- |
| `C:\Users\<用户名>\` | 你自己的桌面、文档、下载、软件配置 | 找自己的文件、找软件的配置文件 |
| `C:\Users\<用户名>\AppData\` | 软件自己写的配置和缓存（默认隐藏） | 软件出问题时清缓存、找日志 |
| `%TEMP%` | 临时文件 | 清理磁盘、看某个安装程序解压到哪了 |

`<用户名>` 是你登录 Windows 的账号名，不是你给自己起的昵称。写文档、写脚本时把这一段写成 `<用户名>`，别人照着敲才不会失败。

### 3.3 路径的三种写法

```text
绝对路径：C:\Users\publieople\Documents\a.txt      从盘符写起，在哪执行都一样
相对路径：.\a.txt  或  ..\b.txt                    相对当前位置，换目录就变
UNC 路径：\\<设备名>\共享名\a.txt                   访问网络共享，注意开头是两个反斜杠
```

写脚本和写文档时**优先用绝对路径**：相对路径换个工作目录就失效，而"在哪执行"恰恰是最容易忘的一条前提。

### 3.4 两个反复坑人的默认设置

1. **隐藏已知文件类型的扩展名**（Windows 默认开启）。于是 `config.json` 显示成 `config`，你以为改的是 JSON，其实系统存成了 `config.json.txt`。**建议第一件事就是关掉它**：资源管理器 → 查看 → 显示 → 文件扩展名。
2. **路径里有空格和中文**。空格在命令行里会被当成参数分隔符，所以路径要加引号：`cd "D:\我的 项目"`；中文本身没问题，但跨系统传输（解压、同步、拷贝到 Linux）时容易出现乱码，做开发的项目目录建议用纯英文。

### 3.5 怎么快速拿到一个文件的真实路径

- 资源管理器里 **Shift + 右键** 文件 → 「复制文件地址」
- 或在资源管理器**地址栏**点一下，路径会变成可复制的文本
- 想直接跳到某个目录：按 `Win + R`，输入 `%TEMP%` 或 `C:\Users`，回车

拿到的是带引号的完整路径，粘贴进文档或脚本前把引号去掉（路径没有空格时可以不留引号）。

## 四、练习

1. 关掉"隐藏已知文件类型的扩展名"，然后在桌面上新建一个文本文件，把它改名成 `test.json`，确认图标和名字都变了。
2. 用 `Win + R` 打开 `%TEMP%`，找出里面最大的三个文件（不知道怎么看大小就先按"大小"排序列）。
3. 打开 `C:\Users\<你的用户名>`，找到桌面、下载、文档这三个目录，写清它们在磁盘上的完整路径。

## 五、验收标准

- [ ] 能口述 `C:\Users\<用户名>\AppData\Local\Temp` 在资源管理器里怎么点进去
- [ ] 能说出关闭"隐藏扩展名"前后，`a.txt` 和 `a.txt.txt` 的区别
- [ ] 能对着一条含空格和中文的路径，写出命令行里正确的写法
- [ ] 能用 `Shift + 右键 → 复制文件地址` 拿到任意文件的完整路径
