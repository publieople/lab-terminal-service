# 快捷键与窗口管理

**什么时候看这一讲**：每天在任务栏上找图标、切窗口切半天、想开个终端还要点三次开始菜单的时候。

## 一、学习目标

学完这一讲，你能：

- 用键盘完成开资源管理器、开终端、锁屏、切窗口、分屏这一整套动作
- 用虚拟桌面把「写文档」和「跑服务」分开，不再靠最小化一堆窗口
- 在程序卡死时，不用重启电脑就能找到并结束它

## 二、前置

[文件与路径](01-文件与路径.md)——你要知道窗口标题栏里的路径和文件名是怎么来的。

## 三、正文

### 3.1 六个 `Win` 键起手的动作

| 快捷键 | 作用 | 用它的场景 |
| --- | --- | --- |
| `Win + E` | 打开资源管理器 | 找文件、插 U 盘后看内容 |
| `Win + R` | 打开「运行」 | 输入 `%TEMP%`、`cmd`、`\\<设备名>` 直达 |
| `Win + L` | 锁屏 | 离开工位，随手一按 |
| `Win + D` | 显示/隐藏桌面 | 找桌面上的文件 |
| `Win + X` | 打开系统菜单 | 里面能直达终端、设备管理器、磁盘管理 |
| `Win + Shift + S` | 区域截图 | 报错截图、贴给同学看 |

`Win + X` 之后按 `I`（或 `A`）能直接打开终端，比在开始菜单里翻要快。

### 3.2 窗口：切、摆、分

```text
Alt + Tab            切到上一个/下一个窗口（按住 Alt 连按 Tab 可循环）
Win + Tab            任务视图：看所有窗口和虚拟桌面
Win + ← / →          把窗口贴到屏幕左/右半边
Win + ↑ / ↓          最大化 / 还原 / 最小化
Alt + F4             关闭当前窗口（卡死时连按两次通常能关掉）
```

分屏的实际用法：左边开文档、右边开终端，对照着敲命令；`Win + 方向键` 连按两次会依次变成四分之一屏，笔记本小屏很好用。

### 3.3 虚拟桌面

```text
Win + Ctrl + D       新建虚拟桌面
Win + Ctrl + ← / →   在虚拟桌面之间切换
Win + Ctrl + F4      关闭当前虚拟桌面（窗口会回到上一个桌面）
```

建议按用途分：一个桌面放编辑器，一个桌面放终端和日志，一个放浏览器。切桌面比在一堆窗口里找要快，而且投屏演示时不容易露馅。

### 3.4 程序卡死时

1. `Ctrl + Shift + Esc` 直接开任务管理器（不用先按 `Ctrl + Alt + Del`）
2. 在「进程」里按 CPU 或内存排序，找到占用异常的那一项
3. 选中 → 结束任务。**先看它的名字再动手**，别把资源管理器一起关了

如果连任务管理器都打不开，`Win + R` 输入 `taskmgr` 试一次；仍然不行再考虑重启。

### 3.5 把终端固定在顺手的位置

- `Win + X` → 终端（或终端（管理员））——需要管理员权限的操作从这里开
- 装好 Windows Terminal 之后，在资源管理器的**地址栏**输入 `wt` 回车，终端会直接开在当前目录，省掉一次 `cd`
- 常用操作固定到任务栏：右键任务栏图标 → 固定；再用 `Win + 数字键` 打开第 N 个图标

## 四、练习

1. 只用一个手（另一只手放桌上）完成：开资源管理器 → 开终端 → 锁屏 → 解锁。
2. 建三个虚拟桌面，分别在每个桌面只放一类窗口，用 `Win + Ctrl + ←/→` 来回切十次。
3. 故意打开一个卡住的程序（或在任务管理器里找一个占内存很高的进程），用 `Ctrl + Shift + Esc` 结束它。

## 五、验收标准

- [ ] 不看键盘能按出 `Win + E`、`Win + R`、`Win + X`、`Win + L`
- [ ] 能说出 `Win + ←` 和 `Win + Ctrl + ←` 的区别
- [ ] 能在三秒内打开任务管理器并结束一个指定进程
- [ ] 能在资源管理器的某个目录里直接开出该目录下的终端
