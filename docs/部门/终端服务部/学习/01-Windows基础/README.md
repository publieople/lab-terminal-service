# Windows 基础

**什么时候看这一章**：刚拿到一台 Windows 电脑，或者一直用电脑但说不清文件放在哪、快捷键只会 `Ctrl+C`。

## 一、这一章教什么

日常操作里最容易被跳过、后面又天天用到的那部分：路径怎么读、窗口怎么管、软件从哪装、系统设置在哪一层。**不教 Office，也不教装机**——那些需要时再单独成章。

## 二、学完能做什么

- 看到任何一条路径，能说出它在资源管理器里的哪个位置
- 用键盘完成切窗口、分屏、开终端、查进程，不用去桌面上找图标
- 装软件时知道去官方渠道还是包管理器，并说得出理由

## 三、前置

不适用——这是全库的起点，只要能打开自己的电脑。
