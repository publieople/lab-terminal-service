# Windows 基本操作

## 一、课程定位

部门里的活，绝大多数从"在自己电脑上做点什么"开始：装一个工具、连一台服务器、传一个文件、看一眼日志、查一个端口。这些动作看着零碎，卡住的原因却常常是同一类——不知道文件实际在哪、不知道程序被谁管着、不知道网络问题该从哪一层开始查。

这门课补的就是这个缺口：把 Windows 当成一台可以被查看、被理解、被排查的机器。学完它，后面的《[Windows 常用软件](Windows常用软件.md)》与《终端环境与配置》才不会退化成"照着敲一遍，报错就卡住"。

本课只讲**操作与查看**。重装系统、组策略、域管理这些内容要么日常用不上，要么该由管理员来做，都不在这里。

---

## 二、面向对象

- 之前主要用手机或平板，Windows 只用来上网和打游戏的新成员；
- 会用鼠标点菜单，但说不清"这个文件到底在哪个目录""为什么软件装不上"的人；
- 需要在自己电脑上排查卡顿、连不上、端口被占这类问题的人。

---

## 三、前置知识

- 会开关机、登录、用浏览器下载文件、解压压缩包；
- 分得清文件和文件夹。

不需要编程基础，也不需要看懂英文界面——下面提到的界面项会给出中英文两种叫法。

---

## 四、学习目标

学完应当能独立做到下面八件事。做不到，就回到第五节对应的小节。

1. 打开文件扩展名与隐藏文件，说清某个文件在磁盘上的完整路径；
2. 纯键盘完成：开资源管理器、开"运行"、切窗口、截图、锁屏；
3. 说清 `PATH` 是做什么的，新增一个用户级环境变量并让它立刻生效；
4. 在任务管理器里定位到占用 CPU、内存或某个端口的进程；
5. 说清"服务"与"计划任务"的区别，并找到一条开机自启项；
6. 用 `winget` 搜索、安装、卸载一个软件；
7. 用 `ipconfig`、`ping`、`nslookup`、`netstat` 做一轮基本网络排查；
8. 说出三处不该乱动的系统位置，以及乱动之后的后果。

## 五、知识模块

### 5.1 文件与路径

路径怎么读、扩展名为什么默认隐藏、`AppData` 与 `ProgramData` 这类隐藏目录放什么、路径里有空格怎么办，见[文件与路径](01-Windows基础/01-文件与路径.md)的三、3.1-3.4。这里只留那一讲没讲的两件事：

- **命名与目录的习惯**：日期写成 `YYYY-MM-DD`（按名称排序就是时间顺序）；一个项目一个目录，里面再分源码、文档、素材；临时文件集中放一个固定的 `_tmp` 目录，清理时整体删掉；文件名尽量不用空格和特殊字符。
- **找文件**：文件多的时候用按文件名搜索的工具（见[Windows 常用软件](Windows常用软件.md)），系统自带的搜索在几十万个文件面前基本等于没有。

### 5.2 窗口与快捷键

开资源管理器（`Win + E`）、开“运行”（`Win + R`）、开系统菜单（`Win + X`）、区域截图、切窗口、分屏、锁屏、用任务管理器结束卡死的进程，整张表见[快捷键与窗口管理](01-Windows基础/02-快捷键与窗口.md)的三、3.1-3.4。这里只补它没列的六个：

| 想做什么 | 按键 |
| --- | --- |
| 剪贴板历史 | `Win + V` |
| 打开设置 | `Win + I` |
| 重命名文件 / 文件夹 | `F2` |
| 新建文件夹 | `Ctrl + Shift + N` |
| 看属性（路径、大小、权限） | `Alt + Enter` |
| 彻底删除（不进回收站） | `Shift + Delete` |

报问题时，“一张截图 + 一句现象”比三段描述有用。

### 5.3 环境变量与 PATH

- 环境变量是给程序读的键值对。用户变量只影响当前用户，系统变量影响所有用户；改系统变量需要管理员权限。
- `PATH` 是一串目录。敲 `node` 时，系统按 `PATH` 的顺序逐个目录找**第一个**匹配的可执行文件。
- 改完 `PATH` **必须重开终端**：已经打开的终端用的是启动那一刻的副本。
- 想知道"实际用的到底是哪一个"，用 `where node`（PowerShell 里也可以 `Get-Command node`）看解析结果。

### 5.4 进程、服务与启动项

- 任务管理器（`Ctrl + Shift + Esc`）：
  - "进程"页看当前谁在占资源；
  - "详细信息"页有 PID 与命令行参数，排查时更有用；
  - "启动"页决定开机自动运行哪些程序，是"开机变慢"最直接的线索。
- 服务是后台常驻程序，由系统统一管理：`Win + R` → `services.msc`。启动类型分"自动""手动""禁用"，遇到"这个服务怎么又自己起来了"，先看这里。
- 同一款软件可能同时有服务、启动项和计划任务，关掉一个不等于关掉全部。

### 5.5 计划任务

- `Win + R` → `taskschd.msc`。计划任务由**触发器**决定何时运行（开机时、登录时、每天几点），由**条件**决定跑不跑——默认勾着"只在交流电下运行"，笔记本拔掉电源就不会跑，这是"昨天还好今天不动"的常见原因。
- 与服务的分工：服务能在用户登录前运行、没有界面；计划任务按条件触发，可以拉起带界面的程序。做"开机自动启动某个程序"，两者都能实现，差别在触发时机与权限。
- 出问题先看"上次运行结果"这一列，再看"历史记录"页——它比翻日志文件好读。

### 5.6 软件的安装与卸载

`winget` 是 Windows 自带的包管理器，可以理解成命令行版应用商店：

```powershell
winget search 关键词
winget install --id <包 ID> --exact
winget list
winget upgrade --all
winget uninstall --id <包 ID>
```

- 安装版会写注册表、可能注册服务与开机启动；绿色版解压即用、卸载等于删目录，代价是不进 `PATH`、也不会自己更新。给部门机器装工具时优先选安装版，出问题好回溯。
- 卸载之后仍有残留：`%APPDATA%` 与 `%LOCALAPPDATA%` 下的配置目录、注册表项。重装同一个软件前先清掉，可以避免"配置怎么改都不生效"。
- 安装位置分三处：`C:\Program Files`、`C:\Program Files (x86)`（按 64/32 位分），以及用户级安装的 `%LOCALAPPDATA%\Programs`。找不到程序时这三处都值得看一眼。

### 5.7 网络排查起手式

顺序比命令本身重要：先确认本机有没有地址，再确认能不能到网关，然后到公网 IP，最后才轮到域名。

```text
① ipconfig /all                     看 IPv4、默认网关、DNS 服务器
② ping <默认网关>                    通不通 → 本机到路由器这一段
③ ping 223.5.5.5                    通不通 → 能不能出公网（用 IP，绕开 DNS）
④ ping <域名>                        能不能解析
⑤ nslookup <域名>                    解析到哪个地址、由谁回答
⑥ tracert <域名>                     从哪一跳开始不通
⑦ netstat -ano | findstr :<端口>      端口被谁占着（拿 PID 去任务管理器对）
⑧ ipconfig /flushdns                 改过 DNS 或 hosts 之后刷缓存
```

- `hosts` 文件在 `C:\Windows\System32\drivers\etc\hosts`，可以手工指定域名解析，改它需要管理员权限。遇到"同一个域名只有我这台指向别处"，先看它。
- ②③④ 这三步能把"链路断了""出不了公网""DNS 坏了"分开，省掉大量瞎猜。

### 5.8 权限与危险区

UAC 弹窗是在问"要不要用管理员权限"。日常用标准用户、只在确有必要时提权，是这台机器最便宜的一道防线。

下面几处不熟就不要动：磁盘管理（分区、格式化、改盘符，一步错就是丢数据）、注册表编辑器（没有撤销）、`C:\Windows` 与 `C:\Program Files` 的权限（改坏会让软件莫名报错）。杀毒软件报毒时先看文件来源与数字签名，不要靠关掉防护来"试试看"。

### 5.9 桌面、设置与基础应用

只留与排查有关的三条：

- **托盘区**：右下角的图标是正在后台运行的程序——弹窗广告、同步工具、输入法状态都在那里；输入法切不过来时先看它（切换用 `Win + 空格`）。
- **系统入口**：按 `Win` 直接开始搜索，比一层层点图标快；`Win + X` 里有终端、磁盘管理、设备管理器。
- **安全与隐私**：Windows 安全中心（Defender、防火墙、设备加密）在设置里能打开。**设备加密开启前先确认恢复密钥已经存好**，忘记恢复密钥会导致数据取不出来。

桌面图标怎么固定、触控板与鼠标怎么调、显示缩放与账户登录方式怎么设，都属于操作习惯；软件选型见[Windows 常用软件](Windows常用软件.md)。

### 5.10 拿到一台新机器之后的顺序

把上面几节串成一条可执行的顺序：

```text
① 系统更新 + 装驱动（厂商官网或系统更新，不要用第三方驱动包）
② 打开文件扩展名与隐藏文件，认一遍自己的目录结构
③ 设置显示缩放、输入法、账户登录方式
④ 用 winget 装第一批工具（见《Windows 常用软件》）
⑤ 配好终端与 Shell（见《终端环境与配置》）
⑥ 检查开机启动项与电源计划，关掉不需要自启的东西
⑦ 把这一套安装命令存成脚本，下次重装不用重新想
```

## 六、实践内容

按顺序做完，每一条都要求能独立重做一遍。

1. **扩展名与隐藏文件**：打开两个开关，找到 `%APPDATA%` 对应的真实磁盘路径，说清它与用户目录的关系。
2. **纯键盘操作**：`Win + E` 进磁盘 → 新建文件夹 → 改名 → 删除 → 从回收站恢复一次。
3. **环境变量**：新增用户变量 `LAB=终端服务部`，重开一个 PowerShell 用 `$env:LAB` 读出来；再往 `PATH` 里加一个目录，用 `where` 验证。
4. **端口与进程**：用 `netstat -ano | findstr :<端口>` 拿到 PID，到任务管理器"详细信息"里对出进程名。可以对着正在运行的机器做。
5. **装与卸**：用 `winget install` 装一个软件、`winget list` 确认、`winget uninstall` 卸掉，再找一眼残留目录。
6. **断网演练**：关掉 Wi-Fi，按 网关 → 公网 IP → 域名 三步定位卡在哪一层，写下结论，再对照实际情况。
