# 现代化 Web 开发 · 第一周：网页开发基础与现代化样式方案

## 一、课程定位

这一周是「现代化 Web 开发」四周课程的第一周，解决的能力缺口是：**从“会用浏览器”到“能自己写出一张像样的网页”**。

在部门学习路径里，它落在「建议学习」一级的「Web 前端开发基础」一格（HTML/CSS 基础 + JavaScript 入门）。做平台运营与内容创作的人要能自己改页面、自己搭展示页，不必每次都等别人排期——这是它值得单独开一周、而不是顺着技术模块顺手学的原因。

本周边界要说清楚：只做**静态页面 + 原生 JavaScript 交互**，不引入任何框架，也不碰构建工具。框架从第二周开始。这样安排是因为“页面本身长什么样”和“页面怎么被组件管起来”是两个能力，混在一起学容易两个都没学扎实。

---

## 二、面向对象

- 没写过网页、但会用电脑管理文件的新成员；
- 已经能写一点代码、但没系统学过 HTML/CSS 的人；
- 需要自己产出展示页、活动页或文档站页面的人。

可以跳过的人：已经能独立完成一个响应式静态页面（写得出语义化结构、用 Tailwind 排得出响应式布局、能用原生 JS 做交互）的人，这一周直接跳过，从第二周开始。

---

## 三、前置知识

- 会管理文件、会用浏览器打开本地的 `.html` 文件。自检：能说清“我的文件存在哪个目录、怎么在浏览器里打开它”。
- 会基本的文本编辑操作。自检：能新建一个文件、存成 `.html`、在编辑器里查找并替换一个词。
- 本部门「计算机基础」一课里“计算机入门概念”和“办公软件基础”两部分，是这一周的直接前置。
- 不需要任何编程经验；不需要装 Node.js，这一周只用浏览器和编辑器。
- 需要装编辑器（VS Code 即可）和联网环境，因为这一周有大量查阅官方文档的任务。

前置不满足时，建议先补「计算机基础」一课里的文件管理与编辑器部分，再回来上这一周。

---

## 四、学习目标

学完这一周，你应该能：

- 掌握 HTML 基本结构和语义化标签
- 熟练使用 CSS 基础和现代样式方案（Tailwind CSS）
- 掌握 JavaScript 基础语法和 DOM 操作
- 能够构建响应式页面
- 培养查阅官方文档的技能

### 评估标准

- HTML 结构合理且语义化
- CSS 样式美观且响应式
- JavaScript 功能正常
- 代码整洁且符合规范
- 按时完成实践任务
- 展示自主学习能力

## 五、知识模块

### 第 1-2 天：HTML 基础

学习内容：

1. HTML 文档结构
2. 常用 HTML 标签
3. 语义化标签

这一块是整周四天里最不能跳的：后面所有的样式和交互都挂在 HTML 结构上，结构写歪了，CSS 只能靠补丁往回救。

### 第 3-4 天：CSS 基础与 Tailwind CSS

学习内容：

1. CSS 基础语法和选择器
2. **Tailwind CSS 配置和使用**

第二项要动手做三件事：

- 安装 Tailwind CSS
- 配置 `tailwind.config.js` 文件
- 使用 Tailwind 类名

顺序上先过一遍原生 CSS 的选择器和盒模型，再看 Tailwind 的类名，才知道每个类名背后省掉了哪几行 CSS。

### 第 5-6 天：JavaScript 基础

学习内容：

1. JavaScript 基础语法
2. DOM 操作
3. 事件处理

这一周只要求“让页面对用户的操作有反应”，不要求写复杂逻辑，也不引入任何框架或状态管理。

### 第 7 天：综合实践

本日目标：

- 整合 HTML、CSS（Tailwind）、JS 技能
- 完成响应式页面开发
- 实践项目构建流程

这一天不引入新语法，只做整合：把前六天零散练过的东西合成一个完整页面。

## 六、实践内容

### 第 1-2 天：HTML 基础

#### 实践任务

- 创建一个结构化的 HTML 页面，包含头部、导航、主要内容区、侧边栏、页脚

#### 文档查阅任务

- 访问 MDN HTML 文档：<https://developer.mozilla.org/zh-CN/docs/Web/HTML>
- 查找并学习至少 5 个不熟悉的 HTML 标签
- 在你的页面中使用这些标签

### 第 3-4 天：CSS 基础与 Tailwind CSS

#### 实践任务

- 将之前创建的 HTML 页面使用 Tailwind CSS 进行样式化
- 实现响应式布局

#### 文档查阅任务

- 访问 Tailwind CSS 官方文档：<https://tailwindcss.com/>
- 学习 “Installation” 和 “Utility-First Fundamentals” 章节
- 查找 Grid 布局和 Flexbox 相关类名
- 在你的页面中实现一个 Grid 布局组件

### 第 5-6 天：JavaScript 基础

#### 实践任务

为页面添加交互功能：

- 点击事件，实现内容切换
- 简单的表单验证功能
- 动态计数器功能

#### 文档查阅任务

- 访问 MDN JavaScript 文档：<https://developer.mozilla.org/zh-CN/docs/Web/JavaScript>
- 查找并学习数组方法（如 map, filter, reduce）
- 在你的代码中使用这些方法

### 第 7 天：综合实践

#### 实践任务：构建完整的响应式页面

- 创建一个作品集或个人网站
- 包含响应式导航栏、Hero 区域、技能展示、项目展示、联系表单
- 使用 Tailwind CSS 实现美观的样式
- 添加 JavaScript 交互功能

#### 自主学习任务

- 选择一个你感兴趣的 CSS 效果
- 查阅相关文档和教程
- 在你的页面中实现该效果

### 学习资源

- 菜鸟教程：<https://www.runoob.com/>
- MDN HTML 文档：<https://developer.mozilla.org/zh-CN/docs/Web/HTML>
- MDN CSS 文档：<https://developer.mozilla.org/zh-CN/docs/Web/CSS>
- MDN JavaScript 文档：<https://developer.mozilla.org/zh-CN/docs/Web/JavaScript>
- Tailwind CSS 文档：<https://tailwindcss.com/>
- W3Schools 教程：<https://www.w3schools.com/>

卡住了先看哪里：先看浏览器开发者工具的控制台报错，再看 MDN 对应标签/属性那一页；Tailwind 的类名写不出效果时，回到官方文档的 “Utility-First Fundamentals” 一节对照。
