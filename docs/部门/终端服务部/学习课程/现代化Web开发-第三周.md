# 现代化 Web 开发 · 第三周：现代化 UI 库和工具

## 一、课程定位

这一周是「现代化 Web 开发」四周课程的第三周，解决的能力缺口是：**从“手写每个样式”到“会用现成的组件库，并且会挑库”**。

第二周结束时，你的界面是自己一像素一像素凑出来的；这一周要换成两件事——把 Tailwind 用深（配置主题、写自定义工具类），以及引入组件库（shadcn-vue 这类“把源码拷进项目”的方案）。后半周的重心则从“用”转到“评”：给一套判据，让你自己能判断一个 UI 库值不值得进项目。

在部门学习路径里，它对应「建议学习」一级「Web 前端开发基础」的延伸段，也是「拓展学习」里「高级前端框架」的入口。选 shadcn-vue 而不是打包好的整库，理由是组件源码进项目、可以按需改，不会因为库的版本升级被迫整体重写。

---

## 二、面向对象

- 上完第二周、能独立写出带组件的 Vue 应用的人；
- 正在维护前端界面、觉得每次调样式都在重复劳动的人；
- 需要给项目选型（要不要引入某个 UI 库、引入了会不会变成负担）的人。

不必学的人：已经用过至少两个 UI 库、并能独立写出选型对比的人，这一周可以只看第 6-7 天的评估标准部分。

## 三、前置知识

- 完成本目录的「现代化 Web 开发」第二周（见 [第二周](现代化Web开发-第二周.md)）。自检：能独立建一个 Vite + Vue 项目，把界面拆成组件，并让数据变化驱动界面更新。

- 会读项目里的构建配置（`vite.config.js`、`tailwind.config.js`）。相关基础见本部门的「现代化 Web 开发」第二周与「容器与编排」一课里讲构建的部分。

前置不满足时，不要跳周：先补第二周；Tailwind 基础不牢的话，回到第一周把 Grid/Flexbox 那一节重做一遍。

学完这一周，你应该能：

- 掌握 Tailwind CSS 高级配置和自定义
- 学会使用 shadcn-vue 组件库

- 掌握多 UI 库集成技巧
- 培养评估和选择工具的能力
- 提高查阅官方文档的技能

### 评估标准

- 掌握 Tailwind CSS 高级配置
- 成功集成 shadcn-vue 组件
- 展示多库集成能力
- 体现工具评估能力
- 完成实践项目
- 展示自主学习成果

## 五、知识模块

### 第 1-3 天：Tailwind CSS 深度应用

学习内容：

1. **Tailwind 配置文件详解**
2. **高级配置技巧**
3. **自定义组件和工具类**

第一项包含：

- `tailwind.config.js` 文件结构
- 主题配置（theme）
- 断点配置（screens）
- 自定义插件

第二项包含：

- 使用 `@layer` 指令
- 变体（variants）配置

第三项包含：

- 使用 `@apply` 指令
- 创建可复用组件类
- 响应式设计高级技巧

这一块放在最前面，是因为后面的组件库都长在 Tailwind 的主题体系上：不先把 `theme` 和断点改明白，组件库装进来只会多一层看不懂的样式。

### 第 4-5 天：shadcn-vue 学习

学习内容：

1. **shadcn-vue 安装与配置**
2. **常用组件使用**
3. **主题定制**

第一项包含：

- 项目初始化配置
- 组件安装命令

第二项包含：

- 基础组件（Button, Input, Label）
- 容器组件（Card, Sheet, Dialog）
- 表单组件（Form, Select, Checkbox）

第三项包含：

- 颜色主题
- 间距和圆角
- 动画效果

shadcn-vue 的工作方式是“把组件源码拷进项目”，所以重点是学会“装完之后怎么改”，而不是背 API。

### 第 6-7 天：magicui 等其他 UI 库

学习内容：

1. **UI 库评估标准**
2. **集成策略**

第一项包含：

- 文档完整性
- GitHub 活跃度
- 社区支持
- 与 Vue 的兼容性
- 性能影响

第二项包含：

- 多库共存考虑
- 冲突解决
- 性能影响评估

最后两天不再给具体库，而是给判据——因为库的流行度变化很快，会评比会用一个库更耐用。

## 六、实践内容

### 第 1-3 天：Tailwind CSS 深度应用

#### 实践任务

- 创建一个包含多个可复用组件的 Tailwind 组件库
- 包括按钮、卡片、表单元素、导航组件
- 使用 `@apply` 指令创建可复用的组件类
- 实现深色模式切换功能

#### 文档查阅任务

- 深入阅读 Tailwind CSS 官方文档的 “Customizing” 章节
- 学习如何创建自定义插件
- 查找并实现一个实用的 Tailwind 插件

### 第 4-5 天：shadcn-vue 学习

#### 实践任务

- 为你的 Vue 应用集成 shadcn-vue
- 使用至少 5 种不同的 shadcn-vue 组件
- 实现一个包含表单、对话框和数据表格的管理界面
- 自定义组件样式以匹配应用主题

#### 文档查阅任务

- 访问 shadcn-vue 文档（或相应库的官方文档）
- 学习如何自定义组件的样式
- 查找并实现一个复杂的组件组合（如带验证的表单）

### 第 6-7 天：magicui 等其他 UI 库

#### 实践任务

- 自主选择一个现代化 UI 库（如 magicui、Framer Motion Vue 版或其他流行库）
- 评估该库的适用性
- 在你的 Vue 项目中集成该库
- 使用该库的特色功能增强你的应用

#### 自主学习任务

- 比较至少 3 个不同的 UI 库（如 shadcn-vue、Headless UI 或其他）
- 分析它们的优缺点
- 为不同场景选择最适合的库
- 准备一个简短的比较报告

#### 文档查阅任务

- 选择一个你感兴趣的新 UI 库
- 详细阅读其官方文档
- 了解其设计理念和最佳实践
- 在你的项目中应用该库的核心功能

### 学习资源

- Tailwind CSS 文档：<https://tailwindcss.com/>
- shadcn/ui 文档：根据具体库提供
- VueUse 文档：<https://vueuse.org/>
- Headless UI 文档：<https://headlessui.com/>
- 社区资源和 GitHub 仓库

卡住了先看哪里：配置类问题先翻官方文档的 Customizing / Installation 两章，再看项目的 `tailwind.config.js` 与 `vite.config.js` 有没有被改乱；组件样式冲突时，先确认是哪一层（Tailwind 基础类、组件库的默认样式、自己的覆盖）在生效，不要直接加 `!important`。
