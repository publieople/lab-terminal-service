# 现代化 Web 开发 · 第二周：Vue.js 框架学习

## 一、课程定位

这一周是「现代化 Web 开发」四周课程的第二周，解决的能力缺口是：**从“会写一个页面”到“会把页面拆成组件、并用数据驱动它”**。

第一周做的页面，改一处内容要翻三处 HTML；这一周要换掉的正是这种写法——把界面拆成组件，让界面跟着数据走。在部门学习路径里，它对应「建议学习」一级「Web 前端开发基础」中的「前端框架初探」一格。

选 Vue.js 而不是别的框架，理由是它对新手更友好（模板写法接近 HTML、官方文档有完整中文）、且部门现有的内容平台与展示页都能用它维护。本周边界：只做单页应用，路由只要求“会用”，不做服务端渲染，也不做状态管理的深度实践——那两项留到第三、四周。

---

## 二、面向对象

- 上完第一周、能独立写出一个响应式静态页面的人；
- 会原生 JavaScript 和 DOM 操作、但没接触过组件化开发的人；
- 需要长期维护前端页面（改一版内容不想翻遍 HTML）的人。

不必学的人：已经能独立用 Vue 或 React 完成一个带组件的单页应用的人，可以跳过这一周。

## 三、前置知识

- 完成本目录的「现代化 Web 开发」第一周（见 [第一周](现代化Web开发-第一周.md)）。自检：不看教程能写出一个带导航、内容区、页脚的响应式页面，并能用原生 JS 让它对点击有反应。
- 会用命令行执行简单命令。自检：能在终端里进入某个目录、执行一条命令、看到输出。命令行的系统训练见本部门的「Shell 与脚本」一课。
- 本机装好 Node.js 与 npm。自检：`node -v` 与 `npm -v` 都能打印版本号。
- 会 Git 的基本操作（提交、拉取、分支）。这一周的练习要进仓库，相关基础见「Git 与协作」一课。

前置不满足时，不要跳周：先补第一周，或者先补 Node.js 与 npm 的安装（第二周第一天就要用）。

## 四、学习目标

学完这一周，你应该能：

- 掌握 Vue.js 开发环境搭建（使用 Vite）
- 理解 Vue 组件系统和模板语法
- 学会使用响应式数据和处理事件
- 能够构建基本的 Vue 应用
- 培养查阅 Vue 官方文档的技能

### 评估标准

- 能够创建 Vue 项目并配置工具
- 理解 Vue 组件系统
- 实现组件间通信
- 完成实践项目
- 展示自主学习能力
- 代码质量和结构合理

---

## 五、知识模块

### 第 1-2 天：Vue 基础概念与 Vite

学习内容：

1. **Vite 项目创建**
2. **Vue 基础语法**

第一项包含：

- Node.js 和 npm 环境检查
- 创建 Vue 项目命令
- 项目结构解析

第二项包含：

- 模板语法（插值、指令）
- 响应式数据绑定
- 组件基础概念

先建项目、再学语法，是因为 Vue 的模板写法要跑起来才知道它对不对；带着一个能热更新的项目学，每次改动都能立刻看到结果。

### 第 3-4 天：Vue 进阶概念

学习内容：

1. 响应式系统深入（reactive, ref, computed, watch）
2. 组件通信（Props, Events, Slots）
3. 生命周期钩子
4. 条件渲染和列表渲染

这一块是分水岭：组件之间怎么传数据定不下来，后面的项目会写成一团。顺序建议是先 reactive/ref，再 computed/watch，最后才是组件通信。

### 第 5-7 天：Vue 项目实践

本段目标：

- 构建完整的 Vue 应用
- 集成现代化工具（Tailwind CSS）
- 实现复杂功能

这三天把前四天的概念合成一个能跑的完整应用，并要求把第一周用的 Tailwind CSS 接进 Vue 项目里，为第三周的 UI 库做铺垫。

## 六、实践内容

### 第 1-2 天：Vue 基础概念与 Vite

#### 实践任务

- 创建一个 Vite + Vue 项目
- 配置 Tailwind CSS 到 Vue 项目中
- 创建多个组件（如 Header、Footer、Card 等）

#### 文档查阅任务

- 访问 Vue.js 官方文档：<https://vuejs.org/>
- 阅读“快速上手”章节
- 了解 Vue 的响应式系统
- 查找并学习组件 Props 的使用方法

### 第 3-4 天：Vue 进阶概念

#### 实践任务

- 创建一个父组件和多个子组件
- 实现父子组件间的数据传递
- 使用事件在组件间通信
- 创建一个列表组件，实现增删改查功能

#### 文档查阅任务

- 学习 Vue Composition API 文档
- 查找并理解 computed 和 watch 的使用场景
- 了解组件生命周期的最佳实践

### 第 5-7 天：Vue 项目实践

#### 实践任务

- 创建一个任务管理应用或个人作品集
- 包含响应式导航、任务/项目列表、表单输入、状态管理
- 使用组件化开发
- 应用 Tailwind CSS 实现美观界面

#### 文档查阅任务

- 查阅 Vue Router 文档：<https://router.vuejs.org/>
- 了解路由的基本概念
- 学习如何在项目中集成路由

#### 自主学习任务

- 选择一个 Vue 生态中的工具或库（如 VueUse、Pinia 等）
- 通过官方文档学习其基本用法
- 在你的项目中尝试使用该工具

### 学习资源

- Vue.js 官方文档：<https://vuejs.org/>
- Vite 文档：<https://vitejs.dev/>
- VueUse 文档：<https://vueuse.org/>
- Tailwind CSS 文档：<https://tailwindcss.com/>

卡住了先看哪里：先看浏览器控制台的报错和 Vue 的警告信息（Vue 的警告通常直接指出是哪个组件、哪个 prop），再回到官方文档对应章节；组件通信的问题优先查 Props 与 Events 两页，不要靠猜。
