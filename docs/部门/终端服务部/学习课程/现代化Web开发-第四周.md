# 现代化 Web 开发 · 第四周：自主学习能力培养

## 一、课程定位

这一周是「现代化 Web 开发」四周课程的最后一周，解决两个能力缺口：

1. **工具链本身要弄明白**——前三周学的是怎么写页面，这一周要知道页面是怎么被打包、优化、发布出去的；不知道这一层，遇到构建报错就只能等人。
2. **从“别人给任务”换成“自己找任务”**——这一周不指定技术，只给一套评估与集成的流程，你自己选一项新技术学完并讲清楚。

在部门学习路径里，它是「建议学习」一级「Web 前端开发基础」的收口，也是通往「拓展学习」一级的过渡带：四周上完，就该按自己的兴趣回学习路径里挑方向了。

---

## 二、面向对象

- 上完第三周、手里有一个能跑的 Vue 应用的人；
- 即将接手独立任务、需要靠官方文档和社区自己解决问题的人；
- 准备往小程序、安卓、iOS 等跨平台方向走，需要先练“自己学会一门新技术”的人。

不必学的人：已经能独立完成构建优化与部署、并且有从零自学一项新技术的经历的人。

---

## 三、前置知识

- 完成本目录的「现代化 Web 开发」第三周（见 [第三周](现代化Web开发-第三周.md)）。自检：能独立把组件库集成进 Vue 项目并改出符合主题的样式。
- 手里有一个前三周做出来的 Vue 应用。这一周的性能优化和部署都拿它当对象，没有现成应用会空转。
- 会命令行执行构建命令。自检：能执行 `npm install` / `npm run build` 并读懂输出里成功或失败的那几行。
- 会 Git 的基本操作（提交、分支、推送）。相关基础见本部门的「Git 与协作」一课。

前置不满足时，先补第三周；没有现成应用的话，把第二周的任务管理应用重新做一遍带过来。

---

## 四、学习目标

学完这一周，你应该能：

- 掌握 Vite 高级配置和项目优化
- 培养自主学习新技术的能力
- 提高文档阅读和理解能力
- 学会独立解决问题
- 为后续学习小程序、安卓、iOS 等跨平台开发做好准备

### 评估标准

- 展示独立学习新技术的能力
- 有效利用文档和社区资源
- 成功集成所选技术到项目中
- 提供有见地的技术评估
- 展示解决问题的能力
- 准备充分的成果展示

---

## 五、知识模块

### 第 1-4 天：工具链深度整合与优化

学习内容：

1. **Vite 高级配置**
2. **性能优化**
3. **项目部署流程**

第一项包含：

- 环境变量配置和管理
- 代理设置（开发环境 API 代理）
- 自定义插件开发
- 构建优化策略

第二项包含：

- 代码分割和懒加载
- 资源优化（图像、字体等）
- 预加载和预获取策略
- 构建产物分析

第三项包含：

- 构建配置
- 部署策略
- CI/CD 基础概念

这四天先配置、再优化、最后部署，顺序不能换：产物分析要拿优化前的版本当基准，否则看不出哪一步真的有效。

### 第 5-7 天：自主学习实践

核心任务：自主选择新技术进行学习和应用。

#### 任务 1：技术评估与选择

从以下列表中选择一个技术，或自主选择一个相关的现代前端技术：

- Vue Router（Vue 路由管理）
- Pinia（Vue 状态管理）
- VueUse（Vue 工具库）
- UnoCSS（原子化 CSS 引擎）
- Nuxt.js（Vue 全栈框架）
- Vitest（Vite 测试框架）
- Playwright 或 Cypress（端到端测试）
- 或其他你感兴趣的现代化 Vue 生态技术

#### 任务 2：自主学习过程

##### 文档研究阶段（第 5 天）

- 访问所选技术的官方文档
- 了解技术背景和适用场景
- 学习核心 API 和概念
- 记录学习过程中的问题和发现

##### 实践应用阶段（第 6 天）

- 在你的 Vue 项目中集成所选技术
- 实现一个具体的功能来验证技术能力
- 遇到问题时查阅文档和社区资源
- 优化实现并确保代码质量

##### 成果展示准备（第 7 天）

- 准备技术演示
- 总结学习过程中遇到的挑战和解决方案
- 分析该技术的优缺点和适用场景
- 提出进一步学习的计划

“读文档 → 动手集成 → 讲清楚”这三步是刻意排在一起的：只读不做学不会细节，只做不讲不知道自己哪里没懂。

## 六、实践内容

### 第 1-4 天：工具链深度整合与优化

#### 实践任务

- 对前几周开发的 Vue 应用进行性能优化
- 配置 Vite 的高级选项
- 实现代码分割和懒加载
- 部署应用到静态托管服务（如 GitHub Pages 或 Netlify）

#### 文档查阅任务

- 深入阅读 Vite 官方文档的 “Config” 和 “API” 章节
- 学习如何编写自定义 Vite 插件
- 了解构建优化的最佳实践

### 第 5-7 天：自主学习实践

#### 自主学习能力评估

##### 评估要求

文档阅读能力：

- 能否快速定位所需信息
- 理解复杂概念的能力
- 将文档知识转化为实践的能力

问题解决能力：

- 遇到错误时的分析能力
- 利用社区资源解决问题的能力
- 调试和排错技能

技术评估能力：

- 评估技术适用性的能力
- 识别技术优缺点的能力
- 预判技术集成风险的能力

##### 实践要求

对于技术评估，需要考虑以下方面：

- **功能特性**：该技术提供什么功能？
- **学习曲线**：学习难度如何？
- **社区支持**：社区活跃度和资源丰富程度
- **维护状态**：项目更新频率和支持情况
- **性能影响**：对项目性能的影响
- **兼容性**：与现有技术栈的兼容性
- **长期维护**：技术的可持续性

对于技术集成，需要完成：

- 详细记录集成过程
- 解决集成过程中遇到的问题
- 优化集成后的代码
- 编写简单的使用文档

##### 成果展示内容

1. **技术介绍**：简要介绍所选技术及其用途
2. **学习过程**：分享学习路径和遇到的挑战
3. **实践成果**：展示在项目中的实际应用
4. **评估分析**：对该技术的优缺点分析
5. **未来规划**：进一步学习和应用的计划

#### 挑战性任务（可选）

- 尝试集成多个相关技术
- 解决一个复杂的集成问题
- 为团队编写一个简单的新技术使用指南

### 学习资源

- Vue.js 生态系统文档
- Vite 文档：<https://vitejs.dev/>
- 技术选型参考网站
- 开发者社区（GitHub, Stack Overflow, Reddit 等）
- 技术博客和文章
- 在线课程平台

卡住了先看哪里：构建类问题先看 Vite 官方文档的 Config 章节与终端的完整报错（不要只看最后一行）；集成新技术时先翻它的官方 “Getting Started”，再看 GitHub 上的 issue 区有没有人踩过同一个坑。

## 七、项目衔接

通过四周的学习，你应该已经掌握了：

1. 网页开发基础技能（HTML、CSS、JavaScript）
2. 现代化样式方案（Tailwind CSS）
3. Vue.js 框架和组件开发
4. 现代化 UI 库使用
5. 工具链配置和优化
6. 自主学习和文档阅读能力

### 为后续学习小程序、安卓、iOS 等跨平台开发的准备

技能迁移：

- Vue.js 的组件化思维可以应用到小程序开发中
- 现代化工具链经验有助于理解其他平台的开发流程
- 文档阅读和自主学习能力是学习任何新技术的关键

后续学习建议：

- 小程序开发：微信小程序、支付宝小程序、uni-app
- 跨平台移动开发：React Native、Flutter、Ionic
- 桌面应用开发：Electron、Tauri
- 后端开发：Node.js、Python FastAPI

持续学习方法：

1. 保持对新技术的关注
2. 定期阅读技术文档和文章
3. 参与开发者社区
4. 实践项目驱动学习
5. 分享学习成果

### 这一课之后接什么

- **回到学习路径**：本课程对应学习路径里「建议学习」一级的「Web 前端开发基础」一格。四周上完，回本目录的 [学习路径](学习路径.md) 按第二级剩下的方向（Web 后端、Docker、AI 与智能体）继续，或直接进第三级挑一个拓展方向。
- **接项目**：带着一个部署上线的前端应用去接本部门项目实践里的真实项目，按项目的复现步骤独立跑通一次。
- **接文档**：把第四周选的这项新技术写成部门知识库里的一页（评估结论、集成步骤、踩过的坑），提一个能通过 CI 的 PR——这既是第 ⑥ 步的入门考核，也是把个人学习变成部门资产的方式。
