## 六、怎么补齐

1. **能当场问到的**（A1、A5、B1）：在部门会上直接定，然后**当场**改文档，别等会后。
2. **需要别人提供的**（C1~C6）：开 Issue 跟踪，说明书里已经按"待主书确定"做了兼容设计，**不阻塞其它工作**。
3. **需要自己做的**（D1~D8、E1~E11）：D 类优先。没有台账和拓扑，其它文档写得再好也落不了地。
4. **补齐后**：删掉本页对应的行，更新相关页面的 `更新` 日期；如果某页所有待补都补齐了，把它从 `状态: 草稿` 改成 `可用`。
