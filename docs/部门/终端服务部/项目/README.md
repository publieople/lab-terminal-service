# 项目

**什么时候看这一节**：要接手一个项目、要在别的机器上再部署一套、或者想知道这台服务器上跑的东西是怎么来的。

## 一、这一节放什么

**一个项目一页**，写清楚它是什么、怎么从零跑起来、现在什么状态、还有什么坑。比赛项目、部门部署、内部小工具都算。

每页按「项目目标 / 环境 / 复现步骤 / 成果 / 已知问题 / 用到的技术」六节写。原则：

1. **能复现**：读者照着第三节能独立跑起来，凡是"当时试出来的"参数都要写清取值和理由。
2. **不重复技术原理**：用到什么技术，链到[参考](../参考/README.md)或[学习](../学习/README.md)，正文只写这个项目特有的部分。
3. **已知问题必须写**：还没解决的、绕过去的、会复发的，各一条。能链到[经验](../经验/README.md)就链过去。
