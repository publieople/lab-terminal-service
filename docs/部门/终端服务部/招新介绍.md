# 招新介绍

**上海中侨大学 · 人工智能学院 · 具身智能研究所** —— 终端服务部

> 一句话：我们负责实验室的服务器与算力、网络与设备互联、Agent 平台与工具链、生成式工作流、边缘设备部署。实验室的算力、模型和设备能不能被每个项目稳定地用起来，是我们的事。

## 一、这个部门在做什么

其它部门的产出是算法、模型、硬件和论文。我们的产出是让这些东西能跑起来的环境：服务器不出事、网络连得通、模型跑得动、设备接得上，实验室的其它工作才能开始。

具体一点：实验室的服务器、网络、AI 工具和设备由我们维护，也由我们教会别人怎么用。

## 二、你会动手做的事

| 方向 | 具体会碰到什么 |
| --- | --- |
| 服务器与基础设施 | 装系统、配服务、备份与恢复、监控告警，让一台机器长期稳定地跑 |
| 网络与设备互联 | 内网组网、端口与域名、远程访问，查"为什么这台机器连不上那台" |
| Agent 与工具链 | 搭 AI Agent、写自动化脚本，把每天重复的操作收成一条命令 |
| 生成式工作流 | 部署 ComfyUI 与 GPU 环境，让实验室的显卡真的跑起来 |
| 技术文档与知识库 | 把踩过的坑写成人人能复现的文档，你正在看的这个站点就是这么来的 |

方向不用一开始就定，进来之后按兴趣走。

## 三、你会得到什么

- 用得上的技能：Linux、组网、容器、GPU 环境、自动化脚本。这些在实验室外面同样值钱。
- 拿得出手的作品：你部署的服务、你写的文档、你修好的故障，都会留在这个公开的知识库里。
- 一套排查习惯：遇到没见过的问题，知道先看什么、再动什么。

## 四、需要什么基础

不需要。我们主要面向大一，从零开始教。

部门里有一条完整的上手路径：补基础概念 → 拿到账号 → 跟着技术模块动手 → 跟一个项目从零复现 → 读别人踩过的坑 → 写出自己的第一篇文档。走完这条路径，你就能独立接手一台服务器。

有基础的话可以跳过前几步，直接从项目开始。

## 五、我们更看重什么

- 能把现象说清楚：什么时候、什么现象、之前做过什么。
- 不会就问，查完写下来。我们不怕不会，怕的是不问就乱试。
- 愿意做别人看得见、也用得上的东西。

## 六、如果你打算选这里

进来第一天你会拿到账号和这个知识库的入口，然后按第四部分那条路径走。中间卡住了，直接找部门里的任何一个人问。
